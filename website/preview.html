Local preview of the website chat widget (website/static/js/agent-widget.js). It loads the same way it does on kubeflow.org. On localhost it calls the agent API at http://localhost:8000/chat. Start the API with make api.

Click the blue button in the bottom-right corner. Use the key icon in the panel header to add your own LLM API key for this tab, or clear it.
